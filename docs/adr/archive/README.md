# Archived ADRs

**Nothing in this folder is live.** These six ADRs record an earlier design that was
replaced wholesale on 2026-08-08. They are kept only as a record of what was tried and
why it was abandoned.

The live decisions are in `docs/adr/`, numbered from 0001.

Do not follow anything here. In particular, these ADRs describe a private repository, a
vendored `.marketplace/` directory, a containerised git server on the Host, a PAT stored
in the Sandbox, and preferences shipped as auto memory. None of those exist in the
current design.
